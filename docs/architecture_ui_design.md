### 1.2 核心功能模块

#### 模块 1：眼底图像分析模块

| 功能 | 描述 | 技术实现 |
|------|------|----------|
| 图像上传 | 支持 JPG/PNG/DICOM 格式 | Vue3 + Axios + MinIO |
| 质量评估 | 自动评估图像清晰度、曝光度 | CNN 质量评分模型 |
| 预处理 | 去噪、增强、标准化 | OpenCV + Albumentations |
| DR 分级 | 0-4 期糖尿病视网膜病变分级 | EfficientNet-B4 |
| 病变检测 | 微动脉瘤、出血、渗出物检测 | YOLOv8 + SegFormer |
| 热力图展示 | Grad-CAM 可视化病变区域 | Matplotlib + Canvas |

#### 模块 2：OCT 图像分析模块

| 功能 | 描述 | 技术实现 |
|------|------|----------|
| OCT 上传 | 支持 DICOM/OCT 原始格式 | DICOM.js + MinIO |
| 视网膜分层 | 9 层视网膜结构自动分割 | U-Net 3D |
| 黄斑水肿 | 液体积聚区域检测与量化 | Instance Segmentation |
| 视盘分析 | 青光眼杯盘比 (CDR) 计算 | DeepLabV3+ |
| 厚度地图 | 视网膜厚度分布热力图 | Numpy + Plotly |
| 随访对比 | 历史 OCT 对比分析 | Image Registration |

#### 模块 3：智能报告生成模块

| 功能 | 描述 | 技术实现 |
|------|------|----------|
| 报告模板 | 可配置的医院定制模板 | Jinja2 + HTML |
| 自动填充 | AI 结果自动填入报告 | Python + PDFKit |
| 医生审核 | 医生确认后签发报告 | 工作流引擎 |
| PDF 导出 | 标准 PDF 格式导出 | ReportLab + WeasyPrint |
| 打印支持 | 支持 A4 打印格式 | CSS Print Media |
| 电子签名 | 支持医生电子签名 | CA 证书集成 |

#### 模块 4：患者管理模块

| 功能 | 描述 | 技术实现 |
|------|------|----------|
| 档案创建 | 患者基本信息录入 | PostgreSQL |
| 病史记录 | 既往史、家族史、用药史 | MongoDB |
| 检查历史 | 历史检查结果查询 | Elasticsearch |
| 随访计划 | 自动生成随访提醒 | Celery Beat |
| 风险分层 | 根据 AI 结果风险分级 | Rule Engine |
