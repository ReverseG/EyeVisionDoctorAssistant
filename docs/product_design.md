# 眼底 AI 产品设计文档

> **辅助诊断参考** - 不替代医生最终诊断

---

## 产品概述

### 产品名称
眼底 AI 辅助诊断系统（EyeVision AI）

### 产品定位
面向医院眼科医生的 AI 辅助诊断工具，提供糖尿病视网膜病变、青光眼、黄斑病变等眼底疾病的智能筛查与分析。

### 目标用户
- 医院眼科医生
- 体检中心医师
- 依未科技研发团队

---

## 核心功能

### 1. 眼底图像分析

| 功能模块 | 说明 |
|----------|------|
| 图像预处理 | 眼底彩照质量评估、去噪、增强 |
| 病变检测 | 微动脉瘤、出血点、渗出物检测 |
| DR 分级 | 糖尿病视网膜病变 0-4 期分级 |
| 可视化标注 | 病变区域热力图展示 |

### 2. OCT 图像分析

| 功能模块 | 说明 |
|----------|------|
| 视网膜分层 | 9 层视网膜结构自动分割 |
| 黄斑水肿 | 液体积聚区域检测与量化 |
| 视盘分析 | 青光眼杯盘比计算 |
| 厚度地图 | 视网膜厚度分布图 |

### 3. 智能报告生成

- 自动生成诊断报告（PDF/Word）
- 病变可视化展示
- 历史检查对比分析
- 随访建议生成

┌─────────────────────────────────────────────────┐

                      ↓

## API 接口设计

### 眼底图像分析 API

```python
POST /api/v1/fundus/analyze
{
  "image_id": "string",
  "patient_id": "string",
  "analysis_type": ["dr_grading", "lesion_detection"]
}

Response:
{
  "dr_grade": 2,
  "confidence": 0.87,
  "lesions": [
    {"type": "microaneurysm", "bbox": [x,y,w,h], "confidence": 0.92}
  ],
  "report_url": "https://..."
}
```

### OCT 分析 API

```python
POST /api/v1/oct/analyze
{
  "image_id": "string",
  "patient_id": "string",
  "analysis_type": ["segmentation", "edema_detection"]
}

Response:
{
  "layers": {...},
  "edema_volume": 1.23,  # mm³
  "cdr": 0.65,  # 杯盘比
  "thickness_map": "https://..."
}
```

## 合规要求

### 医疗合规
- ✅ 所有输出标注为"辅助诊断参考"
- ✅ 不替代医生最终诊断
- ✅ 符合 NMPA 医疗器械软件注册要求
- ✅ 临床验证数据留存

### 数据隐私
- ✅ HIPAA 合规（美国市场）
- ✅ GDPR 合规（欧洲市场）
- ✅ 个人信息保护法（中国市场）
- ✅ 数据加密存储与传输

### 系统安全
- ✅ JWT 身份认证
- ✅ RBAC 权限控制
- ✅ 审计日志完整记录
- ✅ 定期安全渗透测试
